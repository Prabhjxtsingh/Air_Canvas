# Air Canvas Version 1

This is the original desktop implementation using OpenCV and MediaPipe.

## Run

```powershell
python -m pip install -r requirements.txt
python air_canvas.py
```

Use one raised index finger to draw. Use index plus middle finger to move
and select colors from the toolbar. Press `s` to save `drawing.png`, `c` to
clear, and `+` or `-` to change brush size.
